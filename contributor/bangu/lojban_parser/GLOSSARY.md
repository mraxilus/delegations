# lojban_parser

This project is a parser that reads lojban words as The Complete Lojban Language (CLL) defines
them.

## Standards

This project takes its symbols from CLL, which the glossary of
[lojban_tagger](../lojban_tagger/GLOSSARY.md) names under Standards. A standard that two projects
use belongs in the root glossary, so this glossary does not name it a second time.

## Language

The words of lojban are gismu, cmavo, rafsi, tanru, tanru unit, lujvo and brivla. The Architect
selected each one, and the glossary of [lojban_tagger](../lojban_tagger/GLOSSARY.md) defines it
under Words of lojban. This project uses each word with that meaning, and does not write the
definitions a second time.
