The tree of live text

Type lojban, and the tree grows as each word arrives. A worker reads the text as live text, piece by piece, and gives each change of its NIF. This page applies each change, and draws each part from the NIF alone. A word that reaches back, as si or li'u, cuts the NIF back to where it lands.

The script has not run.
A word added at the end goes to the same reader. Any other edit starts a new reader. Stream sends the text again, one word at a time. Merge joins each completed part into the one tree that one pass over the text gives.

Each blue box is a rule of CLL 21.1, or a chain of rules that each hold the next alone: it names the rule nearest the words, then the outermost rule and the count. A red box is an error node, srera, at the byte where the grammar stops. A dashed card is a word that no terminal holds, rivbi. A part in amber is still open: the next change replaces it. Merge drops each word that erasure or fa'o leaves out, and each part before the last su, as one pass does; it names the part that holds an error. The parser is compiled from the Nim source of lojban_parser to JavaScript, and it runs in your browser.
