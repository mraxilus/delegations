# contributor

Contributor projects, grouped by domain. There is one folder for each domain directly under
this one, and one folder for each project under each domain. Each project carries README.md,
PROVENANCE.md, GLOSSARY.md, `<project>.nimble` and `tests/`.

Work on a project from branch `contributor/<domain>/<project>/<name>`, which is the only
folder that the branch may change. See [CONTRIBUTOR.md](../CONTRIBUTOR.md).
