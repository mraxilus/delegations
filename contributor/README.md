# contributor

Contributor projects, grouped by domain: one folder per domain directly under this one,
one folder per project under each domain. Each project carries README.md, PROVENANCE.md,
GLOSSARY.md, `<project>.nimble` and `tests/`.

Work on a project from branch `contributor/<domain>/<project>/<name>`, which is the only
folder that branch may change. See [CONTRIBUTOR.md](../CONTRIBUTOR.md).
