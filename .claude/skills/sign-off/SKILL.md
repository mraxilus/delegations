# Sign-off

The `stop` hook checks a sign-off only once it is on screen, so check yours before you send it.

1. Follow `GUIDE.md`, section "The sign-off", from the read of your queue to the last part.
2. Before you send, check the message against each rule of the guide's "Output contract". The
   hook refuses a message that breaks one.

If this file and the charter disagree, the charter wins.
