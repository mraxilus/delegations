# Rule

The Architect has ruled on decisions from your last sign-off. A ruling that stays in chat is
lost, so record it before you act on it.

1. Follow `GUIDE.md`, section "A decision". It says which decision a reply answers, when to ask
   instead of acting, where the ruling goes, and when the `architect` label comes off.
2. Post the rulings for one item in a single comment there. Write them in your own words, as
   the guide's "Output contract" asks.
3. Act on each ruling, then end the turn with `/sign-off`.

If this file and the charter disagree, the charter wins.
